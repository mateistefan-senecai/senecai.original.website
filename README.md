# SenecAI Website

A modern Next.js website for SenecAI with AI-focused design and smooth animations.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Modern, responsive design
- Animated loading screen with logo
- Smooth page transitions
- Gradient color scheme inspired by the SenecAI brand
- Mobile-friendly navigation
- Placeholder sections ready for enhancement

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Image optimization with Next/Image

## Project Structure

- `/app` - Next.js app router pages
- `/components` - React components
- `/public` - Static assets (logo files)

## Color Palette

The website uses a custom color palette extracted from the SenecAI logo:

- Primary: Blue shades (AI/Tech theme)
- Accent: Purple/Magenta shades (Innovation theme)
- Supporting: White, Black, Gray for text and backgrounds
